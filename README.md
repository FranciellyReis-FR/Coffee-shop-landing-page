☕Coffee Landing Page

Uma landing page responsiva de cafeteria desenvolvida com HTML e CSS, focada em layout moderno, hero section e responsividade mobile.

🚀Tecnologias utilizadas

.HTML5<br>
.CSS3<br>
.Google Fonts (Poppins)

🎯Funcionalidades

.Hero section com imagem de fundo<br>
.Navbar estilizada<br>
.Layout responsivo para mobile<br>
.Botões personalizados<br>
.Seção "Our Skills"<br>
.Estilização moderna com gradientes e tipografia<br>

📱Responsividade 

O proheto foi adaptado para diferentes tamanhos de tela, incluindo dispositivos móveis.

📚Aprendizados

Durante este projeto, pratiquei:

.Flexbox<br>
.Position (relative e absolute)<br>
.Responsividade com @media<br>
.Organização de layout<br>
.Estilização de botôes e tipografia<br>
.Estruturação semântica com HTML<br>

💻Como executar o projeto

1.Clone este repositório:<br>
https://github.com/FranciellyReis-FR/Coffee-shop-landing-page.git<br>
2. Abra a pasta do projeto<br>
3. Execute o arquivo index.html no navegador<br>
